Welcome to
DeroGold

DeroGold is an open-source cryptocurrency with its own network and native coin, DEGO. Use a wallet to send and receive DEGO, mine blocks, run a node, or build on the core software.

GET STARTED

300 Second Blocks

Since block 2,325,000 we slowed down our network to 300 seconds average block time

100 Trillion Total Supply

A maximum supply of 100 trillion DEGO, released gradually through mining. With a five-minute block target and declining block rewards, emission extends over many centuries, including the next 800 years.

CryptoNight UPX/2

DeroGold adopted CryptoNight UPX/2 at block 2,420,000 in 2021. The algorithm supports CPU mining, including on ARM devices.

ASIC Resistant

DeroGold uses an ASIC-resistant proof-of-work algorithm intended to support CPU mining.

Lite Blocks

Our LiteBlocks Technology allows the blocks to be as small as possible, while preserving all of our native privacy features. 

No Premine

We are a no-premine project. We believe in transparency and allowing a fair start for everyone who supports our project.

Proof of Work on Transactions

Every time a user submits a transaction via one of our wallets, or via API, transaction proof of work is checked. This adds a computational cost to transaction submission.

About Us

DeroGold launched in December 2018. The project maintains an independent network and open-source software for wallets, mining and node operation. Contributions and technical discussion are welcome on GitHub and Discord.

Our Journey

2018: DECEMBER

We launched DeroGold in December 2018 as a TurtleCoin fork. We adopted the Cryptonight-Turtle algo, which we stayed with until block 2,420,000.

2019: JANUARY - MARCH

Our first few months we were on the block difficulty target of 10 seconds and the emission speed factor 23.

This was fun, as our blockchain was spitting out blocks on average every 10 seconds (quite often ever 5-6 seconds) and throwing about 12M DEGO block reward at our early miners.

2019: APRIL - DECEMBER

At block height 700,000 we have slowed down our network to 20 seconds block difficulty target and moved to emission speed factor 24. Our block reward reduced to about 5M per block, which was still fun to mine at a block target of 20 seconds.

The Network was lightning-fast and fun to send transactions to any user anywhere around the world.

This was the period of time when we started learning some of the limitations of the Cryptonote-based coins codebase - scalability issues and possible attack vectors.

It was a difficult time, during which we learned a lot and improved!

2020: JANUARY - DECEMBER

In order to keep our network fair use, we decided to take the following three actions.

First, we slowed down our network even further to 300 seconds difficulty target. We kept the emission speed factor.

Second, we implemented Proof of Work for any transaction to be submitted to the network. Transactions with no or not enough PoW are rejected to enter the mempool. 

Third, we capped the maximum block size.

These three actions brought much needed stability to our network. These changes addressed network load and made node operation more manageable.

2021: CRYPTONIGHT-UPX UPGRADE

The v0.6.0 release introduced CryptoNight-UPX at block 2,420,000. This is a historical milestone; use the current core release for downloads.

2022: wDEGO token contract work on TRON.

Historical project milestone, not a current roadmap or availability announcement.

2026: CORE v1.0.1.0

Released on 7 March 2026. The 2026 core refresh includes pruned-node operation, checkpoint-based fast sync and database compaction tools. Version 1.0.1.0 improves bootstrap timestamp and difficulty handling, fixes startup RPC crashes and corrects transaction counts on bootstrapped nodes.

Fast sync is not intended for mining nodes. Release packages are available for Windows x64, Linux x64 and Linux ARM64. Downloads · Node documentation.
